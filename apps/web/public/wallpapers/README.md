# Custom Wallpapers Directory

Drop your wallpaper files (images or looping videos) here.

### Supported formats:

- **Images**: `.png`, `.jpg`, `.jpeg`, `.webp` (high-res recommended, e.g., 2560x1440 or 3840x2160)
- **Videos**: `.mp4`, `.webm` (lightweight, looping video clips for living wallpapers)

### Public URL mapping:

Files dropped into this directory are automatically served statically at:

```
/wallpapers/<filename>
```

For example: `my-wallpaper.jpg` becomes available at `/wallpapers/my-wallpaper.jpg`.
