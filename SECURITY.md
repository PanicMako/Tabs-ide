# Reporting Tabs security issues

Do not put exploitable vulnerabilities, credentials, or private data in a public
issue. Use [GitHub private vulnerability reporting](https://github.com/PanicMako/Tabs-ide/security/advisories/new)
if it is enabled for this repository. If unavailable, open a public issue asking
the maintainer for a private reporting channel without disclosing the flaw.

Include the Tabs version, OS/architecture, affected component, impact, and a
minimal reproduction using synthetic data. Never include API keys, account/auth
tokens, cookies, private source, proprietary prompts, sensitive terminal output,
or credential-bearing repository URLs. Report upstream issues to their owners
when appropriate; the Code-OSS subtree's Microsoft SECURITY.md remains intact.

Tabs is a public beta. Security fixes focus on the current version; no response
time or long-term support promise is made. Update from the repository's verified
release artifacts and inspect the release notes before reporting an older build.
