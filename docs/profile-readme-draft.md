### What I'm building

**[Tabs IDE](https://github.com/PanicMako/Tabs-ide)**: one window for all your projects. Each project gets a tab with its own AI agent chat, a Code OSS editor, browser tabs, terminals and Git. I built it because I was swiping between a dozen windows (Figma, my editor, Codex, two browsers) every day. It's free, open source and in public beta for macOS, Windows and Linux. It started as a fork of [T3 Code](https://github.com/pingdotgg/t3code), and I built the workspace on top.
