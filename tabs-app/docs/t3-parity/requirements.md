## 1. Summary of Scope and Methodology

This ledger establishes the authoritative, line-item parity requirements between Tabs and upstream non-mobile T3 Code at the verified pin. Every requirement has a permanent ID, observable behavior, upstream reference, Tabs baseline state, target implementation, and verification criteria.

### Scope Boundaries

- **In Scope**: All non-mobile functionality across orchestration, persistence, provider switching, delegation, agent toolkits, scheduled tasks, webhooks, companion panel in Agents workspace, file previews, browser media/video recording, historical usage ingestion (especially Antigravity SQLite/protobuf), provider integrations (ACP Registry, Pi, OpenCode 2, Codex managed account), sidebar & thread management, remote environments, safe storage cleanup, CLI service lifecycle, and performance bounds.
- **Explicitly Excluded (Mobile Subsystem)**:
  - Native iOS / Android applications (`apps/mobile/`)
  - Mobile push notifications (`mobile-notifications.md`)
  - Mobile phone keyboard controls and phone-specific gestures
  - Mobile offline queues
  - Simulator / emulator / device-lab subsystem (`components/device/DevicePanel.tsx`, `devices.md`)
- **Preserved Tabs Architectural Invariants**:
  - Embedded Code-OSS workspace (`tabs-code-oss`)
  - Bun / Turborepo monorepo structure
  - Electron `WebContentsView` architecture for native browser isolation
  - Top-level toolbar tool buttons (Agents, Browser, Code, Git, Terminal, Testing)
  - Tabs visual branding, themes, and design tokens
