# Messages and formatting

The message box takes plain Markdown. Tabs can write the symbols for you.

## Formatting shortcuts

Select some text and press:

| Keys | Result |
| --- | --- |
| **Cmd/Ctrl + B** | Bold (`**text**`) |
| **Cmd/Ctrl + I** | Italic (`*text*`) |
| **Cmd/Ctrl + E** | Inline code (`` `text` ``) |

Press the same keys on text that is already formatted to take the formatting off. The draft stays
plain Markdown, so what you send is exactly what you see.

Turn the shortcuts off in **Settings → General → Message box**.
