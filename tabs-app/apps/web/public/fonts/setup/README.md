# Setup-only font assets

The active setup pairing is KS Bistra Regular (400) for headings, Pavot Bold
Italic (700) for "One window.", Aicon Semibold (600) for the
"Tabs Setup" label, and Manrope Regular/Medium for supporting text and controls.
These are the original font weights with no CSS stroke or synthetic bold.
The brand label is compact at 14px.

KS Bistra by Korak Studio:

- https://korakstudio.com/work/ks-bistra-font
- https://fontesk.com/ks-bistra-font/
- Download: https://fontesk.com/download/157262/
- The supplied `KS-Bistra-License.txt` permits personal and commercial use.

Aicon by Eko Bimantara:

- https://fontesk.com/aicon-typeface/
- Download: https://fontesk.com/download/144054/
- The supplied `AICON-License.txt` permits personal and commercial use and
  prohibits selling, modifying, or deriving new font software. The bundled
  `AICON-SemiBold.otf` is unchanged.

Pavot Bold Italic by DBWA is used only for the "One window." accent:

- https://fontesk.com/pavot-font/
- `Pavot-License.txt` states free use for all purposes. The original
  `Pavot-BoldItalic.otf` is unchanged.

ZT Otez Regular is restored from the previously downloaded package:

- https://fontesk.com/zt-otez-serif-font/
- `ZTOtez-License.txt` confirms free commercial use for the supplied Regular
  and Italic styles. Only the original Regular file is used for the label.

The shared `downloadedFonts.css` also registers Pavot Bold and ZT Otez Italic
for the new Themes/Animations heading collection. Both files come from the
previously downloaded, licensed packages. The application loads these faces
from local assets, independently of whether onboarding has been opened.

New heading-only presets are Bistra Signal, Exotica Motion, Moche Urbanist,
Aicon Grid, Mirano Flow, Culont Curve, Hebdomadal Shift, and Hashira Modular.
Studio Signal pairs Coconat page headings with Sun Seed Light section
headings, Syne interface/supporting text, and Menlo code.
Abstract Forms is preserved. Retired preset
definitions remain internal for existing saved settings but do not appear in
the picker.
